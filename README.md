This project demonstrates the configuration and verification of IPv6 networking using Cisco routers and PCs in a simulated environment.
The objective is to understand how IPv6 interfaces, addressing, and connectivity work in a small network topology.

The lab includes:

IPv6 interface configuration on routers

Link-local address verification

Automatic IPv6 configuration on hosts

Connectivity testing between network devices

Basic DNS usage for internet resolution

The configurations and tests were executed through Cisco CLI commands and validated using ping and interface verification commands.

Concepts Covered

This project focuses on the following networking concepts:

IPv6 Addressing

Global unicast addresses

Link-local addresses

Automatic configuration for hosts

Cisco Router Configuration

Interface configuration

IPv6 enablement

Address verification

Network Connectivity

Router-to-router communication

PC-to-router communication

End-to-end ping testing

DNS Usage

The project also demonstrates the use of a public DNS server (Google DNS) for name resolution.



📊 Project Goals

The goal of this lab was to:

Understand how IPv6 works in Cisco networks

Practice router configuration using CLI

Verify connectivity between network devices

Learn how link-local addresses are generated

Test DNS functionality in a simulated network
